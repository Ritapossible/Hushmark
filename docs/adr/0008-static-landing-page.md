# ADR-0008: A static landing page is not a dashboard

- Status: accepted
- Date: 2026-11-02

## Context

AGENTS.md rule 10 forbids a dashboard during the hackathon to protect the schedule. Rita asked
for a front-end in the style of an existing professional site. Judges and the X post need one
link that shows the product working, and HACKATHON.md (Q-012) counts a hosted demo as a plus.

## Decision

Build a static landing page in `site/`: no backend, no login, no user data, no tracking.
- Its evidence section is generated by `scripts/build_site_data.py`, which runs Hushmark's own
  verifiers (checks a–g) on the real recordings. A test fails if the page data drifts.
- It borrows a visual style only: Hushmark's own mark, words and content, nothing that could
  be mistaken for another company.
- Hosting (for example GitHub Pages, which needs a public repository) is decided separately
  by Rita.

## Consequences

- Rule 10 stands: no dashboard, no accounts, no server-side front-end.
- The page cannot overstate the claim: what it shows about recordings is computed, and the
  "not proved" list mirrors THREAT_MODEL.md.
