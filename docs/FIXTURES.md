## Why 08 is a unit test

Changing R1's response to add a finding changes the response bytes, so the signature check
(f) fails before grounding (g) runs. The test would pass for the wrong reason. Fixture 08
calls the grounding check directly with signature-verified input supplied by the test, and
says so in its docstring.

## Rules for fixture files

- Every fixture directory has a `FIXTURE.md` saying whether it is real, derived (and what
  changed), or has no model call.
- Real evidence is never edited. Derived fixtures are generated by a script from the real
  ones, so the change is visible in code.
- Injection payloads are inert: they point at an unreachable URL.
