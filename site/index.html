// Verifiable review for repositories AI agents read

Hidden instructions for your AI agents, caught before merge.

Hushmark is a GitHub check. It finds text in a pull request that human reviewers cannot see, sends only those lines to a model running inside a NEAR AI Cloud TEE, and shows a finding only when the TEE's signature and attestation verify.

See the evidence How it works

// The problem

Agents read what reviewers never see.

AI coding agents follow text in docs, PR descriptions and rules files. An HTML comment or an invisible character is skipped by a human reviewer and obeyed by the agent. Once merged, it steers every agent session on the team.

// 2025 · Pillar Security

Rules File Backdoor.

Hidden Unicode in Copilot and Cursor rules files made the assistants write backdoored code. The poisoned file kept working after it was merged.

// 2025 · Invariant Labs

GitHub MCP injection.

A malicious public issue led an agent to leak data from a private repository through a pull request it opened itself.

// Process

How it works, in five steps.

  1. // 01

    Scan.

    Deterministic detectors read the whole diff, title and body for HTML comments, invisible and bidi characters, hidden HTML and agent rules files. Nothing is executed.

  2. // 02

    Excerpt.

    Only the flagged lines and ten lines of context leave the service. Most pull requests have nothing hidden and cost nothing.

  3. // 03

    Review in a TEE.

    A model on NEAR AI Cloud decides whether each region is an instruction aimed at an AI agent. It runs inside Intel TDX and NVIDIA confidential computing.

  4. // 04

    Verify.

    The response signature, the Intel quote, NVIDIA's signed verdict and our fresh nonce are all checked. Any failure means no finding is shown.

  5. // 05

    Report.

    A Hushmark check on the pull request, with a note on each line, and a receipt whose hash is anchored on NEAR.

// Honest limits

What is proved, and what is not.

Proved.

  • The review code has no shell: nothing in a pull request can make it run a command.
  • A finding was signed inside an attested NEAR AI Cloud TEE for that exact input.
  • Every finding points at a region Hushmark found itself, never where the model says.
  • Only excerpts leave the service, and only to an attested TEE.

Not proved, yet.

  • The Hushmark server itself is not in a TEE in v0.1; it sees the full diff.
  • TEE trust is hardware trust in Intel and NVIDIA.
  • Detection is not complete: forms the detectors do not know are missed.

Full details in THREAT_MODEL.md.
